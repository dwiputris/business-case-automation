# business-case-automation
## This is an automated Business Case Management and Evaluation framework for the Expense Management division of a financial service company.

## The ends
  1. to reduce evaluation lead-time
  2. to provide trackings of expenditure requests
  3. to improve evaluation consistency

## Problem and solution
Current:
Department → Email → Expense Management → Manual Review → Decision
Future:
Department → Portal → Automated Screening → AI Evaluation → Expense Management Review → Decision → Tracking

## Four points of evaluations
| Dimension           | Weight |
| ------------------- | -----: |
| Strategic Alignment |    30% |
| Financial Impact    |    30% |
| Expense Impact      |    20% |
| Value for Money     |    20% |

## The guiding principle
AI recommends. Expense Management decides.
